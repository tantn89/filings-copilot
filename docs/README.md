# Documentation

The root [README](../README.md) is the public overview: what the project does, results,
headline design decisions, quickstart, API and roadmap. The files here hold what the
README and the code cannot say on their own.

| Document | Owns |
|---|---|
| [project-overview-pdr.md](project-overview-pdr.md) | Product intent, users, non-goals, domain terms, hard constraints |
| [system-architecture.md](system-architecture.md) | Boundaries, trust boundaries, decision ledger with rejected alternatives |
| [codebase-summary.md](codebase-summary.md) | Where each concern lives and which tests guard it |
| [code-standards.md](code-standards.md) | Engineering and testing policy, contribution rules |
| [design-guidelines.md](design-guidelines.md) | UI design direction and interface conventions |
| [deployment-guide.md](deployment-guide.md) | Deploy, logs, secrets, spend limits and rollback routes |

The roadmap lives only in the root README (`## Roadmap`), so there is no
`project-roadmap.md`.

Plans and review reports are local working records under `plans/` (git-ignored). They
are not documentation and are not authoritative.
